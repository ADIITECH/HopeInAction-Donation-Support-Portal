# HopeInAction-Donation-Support-Portal
A simple and responsive website that facilitates donations of food, clothes, and money to help the needy. Includes forms and navigation for multiple donation categories. Developed using HTML, CSS, and basic JavaScript integration.
# HopeInAction – Donation & Support Portal

## 🌟 Overview
**HopeInAction** is a clean, responsive web portal that allows users to contribute through food, clothing, and monetary donations. The platform is designed to support NGOs, food shelters, and other charity organizations looking for an easy-to-use online donation form system.

## 📂 Project Structure

## 💻 Technologies Used
- HTML5
- CSS3
- TypeScript (optional support)
- React Icons via `lucide-react` (planned)
- Node.js environment for managing dependencies

## 🚀 Features
- 🏠 Homepage with navigation bar
- 📋 Donation portal with separate buttons for Food, Cloth, and Money
- 🧾 Detailed food donation form
- 🖌️ Stylish layout with responsive design
- 🔧 Easy to expand with other donation categories
